## 1. 目的と合格基準（05 からの引用）

| 項目 | 内容 |
|---|---|
| 目的 | ハイライト・シャドウの調整の画質と速度、プレビューと等倍表示の一致を確認する（AR-4） |
| 検証内容 | 縮小画像からガイドを計算し、タイル処理で参照する方式（04 の 2.2 節・2.7 節）で、ハイライト・シャドウを実装する。手法の候補（ガイデッドフィルタ、ラプラシアンピラミッドなど）を比較する |
| サンプルデータ | 逆光の人物・空と建物など、明暗差の大きい写真 |
| 測定方法 | ハロー（明暗の境目のにじみ）を目視で評価する。処理時間を計測する。縮小プレビューとフル解像度を同じサイズに縮小して差を計算する |
| 合格基準 | ハローが目立たない。PoC-3 のパイプラインに追加しても 33ms 以内。プレビューとフル解像度の差が IQ-07b の範囲内。タイルの大きさを変えても継ぎ目が出ない（IQ-07a の範囲内）。露光量だけを変えたときにガイドが再計算されない。切り抜きを変えても、切り抜いた範囲内の結果が変わらない（04 の 2.7 節。レビュー R-03） |
| 想定工数 | 2 週 |
| 不合格の場合 | 手法を変える。ガイドの解像度を上げる |

IQ-07b（02）: フル解像度で処理した結果を、決まった縮小フィルタでプレビューと同じ大きさに縮小したものと、プレビューとの差が **ΔE2000 の 95 パーセンタイルで 2 以下、最大で 5 以下**（仮置き）。

## 3. この環境で AI が確認した事項（参考: 実機ではない）

この環境の構成は [README](README.md) の 5 章です。**合成画像での値で、実際の写真のハローの目視評価はしていません。判定には使いません。**

- **IQ-07b の計測値**（`crates/genzo-pipeline/tests/engine.rs` の `iq07b_measured_values_do_not_regress` の表。このコンテナで測った値）: 合成の RAW（768 × 512）を、プレビュー（長辺 256、256 × 171）とフル解像度で処理し、フル解像度を面積平均で縮小して比べた ΔE2000（B3、リニア BT.2020）。「強い補正」は露光量 +0.5、コントラスト +30、ハイライト −70、シャドウ +70、白 +20、黒 −20、彩度 +30、自然な彩度 +30、トーンカーブ（点 4 つ）。

  | シーン / 設定 | 95 パーセンタイル | 最大 | 基準（2 以下・5 以下）との比較 |
  |---|---|---|---|
  | busy（模様の混在）/ 既定 | 2.937 | 6.748 | 両方とも超える |
  | busy / 強い補正 | 10.493 | 39.866 | 両方とも超える |
  | thin_lines（細い線）/ 既定 | 3.671 | 4.042 | 95 パーセンタイルが超える |
  | thin_lines / 強い補正 | 9.551 | 10.104 | 両方とも超える |
  | color_edges（色の境界）/ 既定 | 1.431 | 4.068 | 内 |
  | color_edges / 強い補正 | 6.017 | 28.440 | 両方とも超える |
  | high_contrast（明暗差）/ 既定 | 0.000 | 4.101 | 内 |
  | high_contrast / 強い補正 | 1.296 | 11.526 | 最大が超える |

- **回転・切り抜きの位置のずれ**（`genzo-pipeline` の `lib.rs` の doc）: 滑らかな三角波のシーン（300 × 201 → 長辺 100）でも、ΔE2000 の平均が切り抜きだけで約 2、回転 7° で約 5（回転・切り抜きなしでは 0）。
- **合格基準のうち仕組みの部分**（`tests/engine.rs`。合成データ）: タイルの大きさを変えてもタイルに分けない結果と IQ-07a の範囲で一致する（すべての向き）、露光量だけを変えたときにガイドを作り直さない、切り抜きを変えても切り抜いた範囲内の画素が変わらない（回転とガイドを使うトーンを含めて、プレビューとフル解像度の両方）。
- **未確認**: ハローの目視評価、実際の写真での IQ-07b、M1 での処理時間（33ms 以内）、手法の比較。
