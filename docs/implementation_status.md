# 実装の進め方と進捗

設計資料（`docs/01`〜`docs/07`）をもとに、AI が実装を進めるための計画と進捗の記録です。
作業が途中で止まった場合は、この表の「状態」を見て続きから再開します。

- 対象範囲: ロードマップ（`05_poc_and_roadmap.md`）の **M0（開発基盤）の AI の担当分** と、**M2 ＋ M3（現像エンジンとカタログ、CLI）のうち、実機・サンプルデータなしで作って確かめられる部分**。
- 範囲外（人の作業、または実機が必要なもの）: サンプルの撮影、Windows / M1 Mac の実機での計測・目視評価、PoC の合否の判定、UI（PoC-1 / M4）の実機確認。
- 開発環境: Linux のコンテナ。LibRaw・lcms2 は Ubuntu のパッケージ、GPU は Mesa の llvmpipe（Vulkan のソフトウェア実装）で動作を確認する。実機（RTX 3080 / M1）での確認は人が行う。

## 人の判断・確認が必要な事項

各 crate の実装の報告で挙がった、人の判断・確認が必要な事項の一覧です（2026-10-10 の時点。AI が整理）。

- **No.1〜21 の並びは重要度の高い順**で、AI が次の観点で付けた仮の順位です。人が見直してください: (1) 既定の設定ですべての出力の見た目・色に影響する、(2) ライセンス・法的な表現（公開・配布に関わる）、(3) PoC の合格基準の判定や設計の前提に関わる、(4) 設計書の記述の更新、(5) 限られた条件で起きる。
- 「推奨」は AI の意見で、決定ではありません。決めたら [決定事項ログ](decision_log.md) に記録し、この表の行に結果（決定事項ログの No）を書き足してください。
- 数値は、括弧内のコード・doc・テストで確認できたものです。確認できなかったものは「要確認」としています。
- PoC で決めるものは、各 PoC のページ（[docs/poc/](poc/README.md)）の「決めること」にも転記しています。
- **ライセンス・法的な表現（No.4〜6）は、AI の判断で確定しません。** 必要に応じて専門家に確認してください。
- **No.22〜31 は、第 3 波（`genzo-api`・`genzo-cli`）の実装・レビューの報告と統合の確認（2026-10-10）から追加したものです。** No.1〜21 との重要度の順位付けはしていません。「報告による」としたものは、AI がこの環境で再現していない事項です。
