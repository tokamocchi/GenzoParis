# 実装の進め方と進捗

設計資料（`docs/01`〜`docs/07`）をもとに、AI が実装を進めるための計画と進捗の記録です。
作業が途中で止まった場合は、この表の「状態」を見て続きから再開します。

- 対象範囲: ロードマップ（`05_poc_and_roadmap.md`）の **M0（開発基盤）の AI の担当分**、**M2 ＋ M3（現像エンジンとカタログ、CLI）のうち、実機・サンプルデータなしで作って確かめられる部分**、**M4（UI）と M5（MVP。配布を含む）のうち、Linux の開発環境で作って確かめられる部分**（2026-10-12 に追加。利用者の指示「M5（MVP）まで進め、アプリを完成させてください」）。
- 2026-10-13 から、**v1 の機能**（[01](01_feature_inventory.md) の優先度「v1」の 40 件）を 18 のパッケージに分けて 1 つずつ順に実装する（利用者の指示「v1 の機能（全40件）すべての実装を行ってください」）。パッケージごとに下の進捗の表に行を足す（No.25 から）。
- 範囲外（人の作業、または実機が必要なもの）: サンプルの撮影、Windows / M1 Mac の実機での計測・目視評価、PoC の合否の判定、UI（PoC-1 / M4）の実機確認、M5 の受け入れの確認（[m5_acceptance.md](m5_acceptance.md)）、Windows・macOS の配布物の作成と配布。
- 開発環境: Linux のコンテナ。LibRaw・lcms2 は Ubuntu のパッケージ、GPU は Mesa の llvmpipe（Vulkan のソフトウェア実装）で動作を確認する。実機（RTX 3080 / M1）での確認は人が行う。
