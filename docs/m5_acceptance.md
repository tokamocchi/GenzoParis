# M5（MVP）の受け入れの確認の手順

MVP のユーザーストーリー（[01 の 5 章](01_feature_inventory.md)）を満たしているかを、**人が Windows と macOS の実機で** 確かめる手順です。ロードマップの [2.4 節](05_poc_and_roadmap.md) の「受け入れの確認」の列を、操作の手順と確認点に書き下したものです。

- 作成: AI（2026-10-12）。画面の文言・操作は実装に合わせて書いていますが、**実機では未確認** です。手順が実際の画面と違う場合は、この資料を直してください。
- 結果は、各表の「結果」の列に「OK / NG（内容）/ 保留」と日付・OS・確認した人を書いてください。NG は [implementation_status.md](implementation_status.md) の表に移して、直すかどうかを決めます。
- 性能の目標（PERF-xx）の計測のルールは [docs/poc/README.md](poc/README.md) の 1.8 節の要約に従います。ここでは「体感で明らかに遅くないか」と、計測が必要な項目の印だけを付けます。
- **個人の写真（人物・自宅の位置情報を含むもの）の結果やスクリーンショットをリポジトリに入れないでください**（[05 の 3 章の注意](05_poc_and_roadmap.md)）。
